# 04 — 展示路由用量并完成真实效果验收

**What to build:** 用户可以看到每轮建议与实际路线、未采用建议的原因、Jev 耗时和可用缓存用量，并在设置页分别控制展示与记录。用户依据真实 ctapi 集成结果和固定 Pro 对比评估理解插件是否值得开启，而不是依赖模型占比或猜测的节省数字。交付包含可安装的完整产品、真实验证证据及安装使用说明。

**Blocked by:** 02 — 提供长上下文与缓存切换保护；03 — 完善思考强度、手动覆盖与会话恢复。

**Status:** ready-for-agent

**Parent:** 《dsh Jev 自动模型路由插件》正式规格。主要覆盖用户故事 10、40–44、46–47，并整体验收 01–03 的交互；01 是经 02、03 传递的依赖，不重复列为直接阻塞。

## Acceptance criteria

- [ ] 设置页提供独立的 `showDecision` 与 `recordMetrics`，默认均开启，保存与刷新生效；用户可以只关闭展示或只关闭记录。两个开关不影响实际路由，关闭记录也不禁用路由所需的短期缓存证据。
- [ ] 在会话中展示已采用的实际模型、可用思考档位、Jev 建议及规则／回退原因，明确区分“建议切换但被保留规则拦截”和“已经切换”。消费已提交的回合决定，不重新推断或编造 Jev 的解释。
- [ ] 展示与结构化记录包含策略版本、可用的 Jev 实际模型版本、分类耗时、建议与实际路线、规则原因和回退状态；有 usage 时记录分类及执行的 token/cache 用量，和对应实际请求关联。
- [ ] 沿用 dsh 的未缓存输入、缓存读取和写入计数语义，不重复计算；未报告的字段明确标为未知。历史命中不展示为下一次命中保证，不因同供应商或相同 cache key 宣称共享缓存。
- [ ] 诊断记录不默认保存对话原文、工具原文或凭据；普通设置读取、日志与界面不得暴露密钥。展示开关不改变模型输入、会话重建或稳定缓存前缀。
- [ ] 缺少可信价格或用量时不显示虚假的节省金额／百分比。有可信数据的评估须计入 Jev、执行模型和重试成本，不能以模型分布、单价差或分类置信度替代总费用与质量评估。
- [ ] 通过真实 Loader／Web profile 组合验证从用户设置与输入到请求、持久化记录和界面展示的路径；覆盖实际切换、规则保留、回退、字段缺失以及独立关闭展示／记录，真实组件与内部服务保持使用实际实现。
- [ ] 将 01–03 的无密钥回放和界面证据组合验收，特别覆盖长上下文保留模型时仍可调整合法强度、分类期间关闭／手动覆盖、恢复后保持路线和规则计数；测试不重复依赖或改写其他票的内部实现。
- [ ] 从完整安装插件的 dsh Web profile 演示仅开启／关闭两种状态。关闭没有 Jev 请求；开启且选择 Auto 时实际路由，手动固定优先，已有会话与子 Agent 不被接管，全局默认模型不被自动路由更改。
- [ ] 对 `ctapi/deepseek-v4-flash-vip` 和 `ctapi/deepseek-v4-pro-vip` 分别进行真实基本生成、工具调用、上下文能力与实际思考档位验证，并记录网关是否返回可用 usage。缺凭据或服务不可用时明确标注未完成，不能用 mock 成功或跳过日志宣称通过。
- [ ] 完成真实 Jev 到 ctapi 的小规模端到端路由验证，核对建议、约束结果和实际执行模型；不要求单次调用必然缓存命中，不为验证而自动重跑已有用户任务或工具副作用。
- [ ] 用同一组常规任务、复杂任务、短追问及长上下文场景比较固定 Pro 与自动路由，采用相同完成标准，记录任务完成与修正次数、分类开销、用量、缓存和延迟；区分冷暖缓存条件，不设置廉价模型占比目标。
- [ ] 交付评估记录，分清实测数据、缺失字段与推断，只给出样本能支持的结论。工具／强度能力未确认的候选不得标成已验证，小样本不承诺普遍等质量省费。
- [ ] 提供安装、构建、启停、凭据配置、Auto／固定选择、常用／高级设置、回退行为、网关限制和诊断说明，准确说明默认值是初始配置而非实测最优，不引入观察模式、价格编辑器或额外产品范围。
- [ ] 完整插件通过适用类型、构建、包导出、配置、界面本地化与卸载检查，测试自有端口、临时文件和进程完整回收。01–03 原有验收持续通过；真实模型验证若仍有阻塞，明确保留未完成项而不关闭本票。

## Scope and handoff

- 本票是可见用量与可追溯评估的纵向交付，不是将所有测试集中到最后；01–03 各自必须先带着对应功能与集成测试完成。
- 不新增价格表编辑、最低节省比例、观察模式、自动质量纠正循环或跨模型故障恢复。评估可记录有来源的价格，不因此扩展产品设置。
- 实施该票时完成真实集成和效果验收；本票的创建不代表已安装插件、已有可用凭据或已完成付费调用。
