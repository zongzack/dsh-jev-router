# 01 — 跑通可安装的逐回合自动路由

**What to build:** 用户可以在现有 dsh Web profile 安装插件，通过设置页配置 Jev 凭据、候选模型和默认回退模型，开启后在主会话选择 Auto，让 Jev 的模型选择真正作用于本轮请求，并在工具续步中保持路线。关闭时不调用 Jev、不干预原有模型选择。这是一条从安装、配置、用户输入到实际模型回复与会话记录的完整可演示路径。

**Blocked by:** None — can start immediately.

**Status:** ready-for-agent

**Parent:** 《dsh Jev 自动模型路由插件》正式规格。主要覆盖用户故事 1–12、15–16、18–21、24–25、36、42、45–46；真实网关能力与最终效果验收由 04 完成。

## Acceptance criteria

- [ ] 独立 Cordis 包提供 Host 与 Client 入口，可通过 dsh 支持的插件加载方式安装到 Web profile。提供可复现的开发安装与启动说明，不建立额外转发代理，不修改主循环；若需要局部整理选模接入，在本票先完成并保持现有行为通过验证。
- [ ] 设置页只提供开启／关闭，首次安装默认关闭；开启后直接应用模型决定，不存在观察、shadow 或仅分类不执行的产品模式。
- [ ] 用户可配置并持久化 `enabled`、`candidateModels`、`defaultModel` 和 `apiKeyEnv`。配置错误、保存失败和版本冲突有清楚反馈，无效配置不部分生效，刷新后恢复已保存值。
- [ ] 候选记录具体 provider/model、能力描述与档位，初始为 `ctapi/deepseek-v4-flash-vip` 和 `ctapi/deepseek-v4-pro-vip`。拒绝重复或无法解析的候选，不以名字推测其他模型的能力。
- [ ] 密钥沿用 dsh credentials，普通配置仅保存引用；读取设置、读回凭据状态及诊断输出不返回密钥明文。设置页说明有限分类材料将发送至 TypeSafe。
- [ ] 开启时新建主会话默认 Auto；已有会话保持原选择，需主动切入 Auto。已固定的模型不被接管，子 Agent 排除，普通 fork 不因父会话关系被误排除。基础 Auto／固定选择可操作，竞态与恢复场景由 03 完善。
- [ ] 对一个由用户输入开始的 turn，最多发起一次 Jev 分类。一次接收批次共同参与判断，同轮的工具 step 和供应商请求重试复用实际路线；不因工具续步再次付费分类。
- [ ] 使用 TypeSafe 的 System One API、Bearer 凭据和 `jev-latest`，验证结构化选项并仅应用允许的模型。分类材料有预算，初始总等待上限为 2,000 ms、序列化 state 预算为 6,000 Unicode 字符；相应高级配置界面与上下文增强由 03 完成。
- [ ] 请求前检查可知的模型窗口与输入模态；未知能力不当作无限支持，无合法候选不向 Jev 提交空选项。思考强度适配由 03 完成，本票不暴露尚未生效的思考开关或发送猜测的档位。
- [ ] 模型选择在系统提示组装与实际请求间保持一致，并正确组合现有选择器的 waterfall。模型切换通知与模型可见内容可从会话记录重建，不修改已冻结请求，不通过会改写全局默认模型的命令执行自动切换。
- [ ] 执行模型接收 dsh 正常构建的完整有效历史，不以 Jev 的截断材料替代会话，不为切换模型额外摘要或裁剪上下文。
- [ ] Jev 缺凭据、超时、服务错误或无效结果时，沿用当前有效模型；没有当前模型时使用配置默认模型，都不可用时显示明确错误。回退与实际执行模型可见，不把无效建议部分应用。
- [ ] 关闭插件后没有新的 Jev 调用；用户取消或卸载后未完成分类不能迟到生效。保留 dsh 原有请求重试，不引入跨模型整轮重跑。更全面的竞态矩阵归 03。
- [ ] 形成以实际提交结果为准的回合路由记录，至少能观察建议路线、实际路线和采用／回退原因。02、03 可在同一回合决策流程补充证据或约束，04 可消费已提交结果；不为未来功能添加新的公共服务层。
- [ ] 通过真实 Loader／Web profile 组合测试，从用户输入验证出站模型请求、工具续步、持久化日志和基础界面。仅替换 Jev／模型网络及必要时间；包含关闭零调用、开启实际切换、候选拒绝、基本回退和全局默认不变。
- [ ] 加入无密钥会话回放，覆盖选模及同轮工具续步；基础设置保存和凭据不可读回有用户可见行为测试。类型、构建、包导出及适用配置检查通过，加载与正常卸载没有重复监听或残留贡献。

## Scope and handoff

- 本票不承担 02 的长度阈值、保持回合数和缓存软偏好，不把这些尚未实现的控制显示为已生效。
- 03 基于本票的回合生命周期与会话控制，完善上下文依赖、思考强度和恢复／取消竞态；不重复搭建模型选择器。
- 本票自身必须可安装并完成一次自动路由演示，不能只交付包骨架、配置表单或 Jev 客户端。

## Comments

- 用户已确认恰好四票的拆分与依赖。本票是当前可立即开始的 frontier；完成它后 02、03 可分别推进。
