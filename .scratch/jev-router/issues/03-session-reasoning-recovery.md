# 03 — 完善思考强度、手动覆盖与会话恢复

**What to build:** 用户在真实多轮会话中可以让短追问继承相关任务含义，按网关支持情况自动调整思考强度，并在手动选模、取消、分类超时、恢复会话或热更新时保持可预测的控制。用户可以在高级设置调整分类超时与材料预算，界面明确展示不支持的能力或故障回退，执行失败不会重跑整轮任务。

**Blocked by:** 01 — 跑通可安装的逐回合自动路由。

**Status:** ready-for-agent

**Parent:** 《dsh Jev 自动模型路由插件》正式规格。主要覆盖用户故事 6–7、13–23、34–39、45–46；复用 01 的基本开关、分类和回退，不重新实现它们。

## Acceptance criteria

- [ ] 高级设置提供并持久化 `routeReasoning`、`jevTimeoutMs`、`jevMaxStateChars`，初始为开启、2,000 ms、6,000 Unicode 字符；输入校验、刷新恢复、保存失败及版本冲突遵循既有设置行为。
- [ ] Jev 同一次请求分别判断需要的能力和思考深度，不能为了思考深度再多付费分类一次；回答校验失败不部分应用模型或强度，低置信度不作为强制升级条件。
- [ ] 推理档位以运行时目录和真实适配器能力为准，仅发送目标模型明确支持的值；不照抄原生 DeepSeek 或 Codex 的固定枚举。关闭强度路由时保留原有有效设置／目标适配器默认行为。
- [ ] 未声明或不支持思考调整的模型仍可完成模型路由，界面清楚说明能力不可用；显式配置不支持的档位应被拒绝，不静默发送错误值或把思考强度当作模型能力替代。
- [ ] 分类 state 包含当前输入和有限相关任务证据；对“继续”“按第二种做”等短回复补充前一任务或相关助手提议，必要时携带有限工具结果片段，避免仅按短句长度判断复杂度。
- [ ] 材料预算覆盖序列化 state 的全部字段名、内容和结构，按 Unicode 字符计量；中英文、超长单条内容、明确截断以及最低有效预算都有验证。无法容纳有效材料时给出明确错误／回退，不静默超限。
- [ ] 用户或工具内容仅作为证据，不能改写候选白名单或插件规则。分类材料截断不改变执行模型的完整有效历史，不新增摘要交接流程。
- [ ] 普通设置在下一用户 turn 生效；模型与思考档位一旦采用，同轮工具 step 与供应商内部重试保持一致，不因重试或重新组装提示重新分类。
- [ ] 手动固定模型后停止该会话的自动干预，直到主动切回 Auto。分类进行中手动覆盖或关闭插件，应取消未生效分类并拒绝迟到结果；已发出的模型请求不强制重跑，后续请求尊重用户选择。
- [ ] 已有会话、主会话、普通 fork 和子 Agent 的作用范围保持 01 的约定；两个并发会话的分类结果、取消信号和选模不串用，自动路线不污染全局默认模型。
- [ ] Auto／固定选择可在会话恢复后保留。恢复已开始的 turn 时使用已记录实际路线，不因内存状态丢失重新分类或切换；不可确认缓存证据恢复为未知，不伪造历史命中。
- [ ] 分类超时覆盖该次调用的总等待，终止请求后按原有回退顺序处理；缺凭据、认证／服务错误、非法 JSON／选项、无合法候选和无回退路线都有用户可理解的状态，取消不能当作故障启动新执行。
- [ ] 执行模型在输出前或输出后报错时，保留 dsh 原有请求重试与错误展示；不引入跨模型整轮重跑，也不重复已经发生的工具副作用。
- [ ] 用户取消、会话销毁、插件卸载和热更新清理旧请求、监听与 UI 贡献；迟到结果不能写入新的 turn 或覆盖新设置。卸载后再次加载没有双重分类或重复通知。
- [ ] 通过真实 Loader／Web profile 组合验证高级设置到实际出站参数及持久化日志的完整路径，覆盖短追问、支持／不支持思考档位、同轮强度保持、材料预算及错误回退；测试替身仅用于外部网络和时间。
- [ ] 竞态测试以最终请求、日志、界面和工具副作用为断言，覆盖分类期间手动覆盖／关闭／取消、恢复、多会话与热卸载；补充故障回退的无密钥会话回放。适用类型、构建、配置及本地化检查通过。

## Scope and handoff

- 本票仅依赖 01。测试可以在未启用 02 约束的基础路线完成；02 自己负责保持计数与上下文／缓存规则，本票不依赖其私有状态。
- 01 提供的基础回退继续使用，本票完善异常矩阵和生命周期，不增加自动跨模型故障重跑、观察模式或熔断配置。
- 04 在完整组合中验证 02 的保留模型规则与本票的同模型强度调整、取消和恢复能够同时成立。

## Comments

- 用户已确认本票仅被 01 阻塞，和 02 之间没有阻塞边。01 完成后可独立演示短追问、思考适配和手动覆盖／恢复。
